# WorldGate 26.1.2 Modpack

This directory defines the official distributable modpack for Minecraft 26.1.2.

The generated `.mrpack` contains:
- WorldGate
- Fabric API

The pack declares Minecraft 26.1.2 and Fabric Loader 0.19.3 as dependencies so compatible launchers can install the correct loader automatically.

Java 25 is required by the WorldGate 26.1.2 build.

The modpack is generated by `.github/workflows/modpack.yml` on every push to `main` and can also be run manually. It is generated from the exact JAR produced by the normal Gradle build, so the modpack does not carry a separately maintained copy of WorldGate.

Do not put secrets, Firebase credentials, backend tokens, or relay credentials into the modpack.
